# Inkjet-printer-printhead-keep-clean-auto-print-test-page-weekly

save the files into C:\Scripts folder (create if needed)

schedule a task in Windows task scheduler (pull up task scheduler in search window) and click 'create basic task'

name the task, add a description, and set a schedule (I chose weekly, Sunday morning)

next, under action, choose 'start a program' and point the script to the 'PrintColorTest.bat' file in your scripts folder.

Sit back and no longer worry your print heads will be all dried out when you need to print something.
